# NUC8 現場型態 fixture：未偵測到螢幕（#448）

用途：`test/powershell/unit/gui_no_display_tests.ps1` 以 NUC8 重新開機後的現場型態，重放螢幕與圖示驗收在沒有螢幕時只回報 worker 退出碼的問題。

## 來源與限制

- `scene.json` 是依 issue #448 記錄的現場事實整理的**去識別型態**，不是原始擷取檔：PnP 螢幕裝置皆不在、主畫面 640x480、worker 排程退出碼 1、未修版入口訊息。
- `PhantomMonitors` 依一般 Windows 型態補入（曾接過、目前不在的裝置），用來確認判定只看目前存在的裝置；現場是否列出這類裝置、每項欄位值均未擷取。
- 現場的 Windows 螢幕數、縮放值與 worker 結果檔內容未擷取。`ScalePercent` 為合成值；測試中的螢幕數以「未知」處理。
- 測試以替身取代 PnP 查詢、排程、原生解析度與圖示介面，不代表實機結果。實機對照須另行執行。
